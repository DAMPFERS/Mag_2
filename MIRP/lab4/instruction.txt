Реализация MPI: Microsoft SDK (Microsoft MPI)

Инструкция по компиляции и запуску файла:
1. Извлеч содержимое архива
2. Зажать Win+R, ввести cmd и нажать Enter
3. Перейти в директорию с разархивированными файлами (cd <Путь в директорию>)
4. Скомпилировать файлы: 
    Команда для компиляции программы с MPI( MS реализация MPI) : gcc mpi_prog.c -o mpi_prog.exe -I<Путь в директорию с заголовочными файлами MPI> -L<Путь в директорию с библиотекой MPI> -lmsmpi  

    Библиотека находится в файлах include и lib:
        gcc mpi_prog.c -o mpi_prog.exe -I".\include" -L".\Lib\x64" -lmsmpi или (gcc mpi_prog.c -o mpi_prog.exe -I".\include" -L".\Lib\x86" -lmsmpi)
	или
	gcc mpi_prog.c -o mpi_prog.exe -I"C:\Program Files (x86)\Microsoft SDKs\MPI\Include" -L"C:\Program Files (x86)\Microsoft SDKs\MPI\Lib\x64" -lmsmpi (или x86)


    
Если возникают проблеммы с компиляцией, то можно попробовать запустить через visual studio:
1. Создать проект в visual studio, добавить в исходные файлы, файл main.cpp, вставить в него код программы
2. Зайти в "Свойства проекта" -> С/С++ -> Общие -> Дополнительные каталоги включаемых файлов -> изменить -> добавить -> "выбрать директорию с установленным Microsoft MPI, обычно это "C:\Program Files (x86)\Microsoft SDKs\MPI\Include"" -> Применить
3. Зайти в "Свойства проекта" -> Компоновщик -> Общие -> Дополнительные каталоги библиотек -> изменить -> добавить -> "выбрать директорию с установленными библиотеками Microsoft MPI, обычно это ":\Program Files (x86)\Microsoft SDKs\MPI\Lib\x86" " x86 или x64, в зависимости от того что стоит в диспетчере конфигураций (активная платформа решений)-> Применить
4. . Зайти в "Свойства проекта" -> Компоновщик -> Ввод -> Дополнительные зависимости -> изменить ->  ввести msmpi.lib -> Применить


Запуск файла:  
    mpiexec -n <количество потоков> mpi_prog.exe
    <кол-во строк матрицы> <кол-во столбцов матрицы>
    <кол-во строк подматрицы> <кол-во столбцов подматрицы>

    Пример:
    mpiexec -n 4 mpi_prog.exe
    1000 1000
    10 10
